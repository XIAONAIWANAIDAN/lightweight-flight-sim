# 轻量模拟飞行 · Light Flight Sim Lite

一款能在手机浏览器里直接打开就飞的轻量飞行模拟游戏：单个 HTML 文件、免安装、无需服务器，从登机、推出、开车、滑行、起飞、巡航到进近自动着陆，走完一整套航班流程。

> 本仓库为**开源发布版**：已移除开发者测试入口与云存档（飞行记录保存在本地浏览器中），鹿寨机场在本版中更名为「训练场」。

## 玩法速览

- **完整航班流程**：登机 → 推出（牵引车）→ 发动机启动 → 滑行（金圈逐点引导）→ 对正跑道 → 起飞 → 巡航 → 进近 → 自动着陆 / 手动着陆 → 滑回停机位 → 下机结算
- **机队（7 型）**：塞斯纳 172、空客 A320、波音 737-800、波音 787-9、空客 A350-900、空客 A380、波音 747-400
- **机场（87 座）**：全国主要国际机场按真实经纬度摆进同一个世界（机场间距离 1:5 压缩、跑道按真实长度/方向 1:1），每座机场含平行滑行道、联络道、成排停机位与航站楼，共 3100 多个机位；另有一座虚构的「训练场」供本场起降与穿环训练
- **仿真系统**：自研系数法气动（迎角/失速/地面效应）、舵面-力矩式操纵惯性、逐型襟翼构型与 VFE 包线、三层刹车/反推模型、自动驾驶（航向/高度/速度 + 自动油门 + 全自动着陆，含侧风蟹形与去蟹）、24 项随机/指定故障、动态天气与真实风场、ATC 语音与字幕
- **飞行记录**：每完成一趟航班自动生成 RFS 风格飞行报告（四阶段时刻、分段耗油、起飞/进近/着陆参数快照），保存在本地，可导出/导入 JSON 备份

### 操作

- 左侧虚拟摇杆：下拉 = 拉杆抬头，上推 = 推杆低头，左右 = 压坡
- 右侧滑杆：油门；刹车为点按锁存（点一下 ON，再点 OFF）
- 大面板（自动驾驶、发动机、系统、检查单、航图等）均为点开才出现，平时只保留边缘小按钮与底部数据带
- 建议横屏游玩（竖屏时画面会自动旋转为横屏布局）

## 技术说明

- [Three.js](https://threejs.org/) 渲染，全部逻辑与资源内嵌于单个 HTML 文件（约 69 MB）
- 无后端、无账号系统；唯一的对外请求是可选的实时天气（open-meteo）
- 地面物理按实体道面高度与逐轮起落架接触模型求解；地形为程序化山体（广西名峰锚定）+ 卫星影像披覆
